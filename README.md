# 金属算量 · 截面特性与理论单重

将两个 Windows 老工具合并为一个计算器，提供**网页版**与**exe 桌面版**两种形态：

| 来源程序 | 原有功能 |
|---|---|
| `金属材料单重计算程序.exe`（中石化兰州设计院，2000） | 按材质与截面尺寸计算理论单重 kg/m |
| `截面特性.exe`（钢结构 Detail 模块，2004） | H型钢/工字钢/槽钢/矩形管的面积、惯性矩、截面模量、回转半径 |

## 使用方式

**方式一：exe 桌面版（推荐）**

直接运行 `dist/金属算量.exe` —— 单文件，双击即用，无需安装、无需联网。详见 `desktop/README.md`。

**方式二：网页版**

双击 `index.html` 即可。若浏览器限制了本地脚本，可在目录内启动临时服务：

```bash
python -m http.server 8823
# 浏览器打开 http://127.0.0.1:8823/index.html
```

## 功能

### 理论单重
- **19 类截面**：工字钢、槽钢、H型钢、不对称工字钢、T型钢、等/不等边角钢、
  圆钢、方钢、扁钢、钢板、圆头扁钢、钢管、六角钢、六角中空钢、方管、矩形管、
  箱形截面、C 型钢（冷弯卷边）
- 每类均支持「查国标表」与「自定义尺寸」双模式
- **33 种材质**，按 钢 / 铸铁 / 有色 / 其他 四组分类
- 输出：截面积、每米重量、每米体积、**外表面积**、**内表面积**、合计涂装面积
- 计算长度可调，默认 6m，改动实时联动

### 截面特性
- 面积 A、惯性矩 Ix/Iy、截面模量 Wx/Wy、回转半径 ix/iy、形心位置与偏距
- 国标型号直接取规范表值

### 截面大样图
- 全部截面按真实比例绘制，含中心轴（点划线）、45° 剖面线、形心 G 标记与尺寸标注线
- **支持亮色 / 暗色主题**，图形颜色随主题自动切换

### 批量算量
- **录入即预览**：改任意输入框，下方即时显示单重、总长、净重、损耗后重量、
  内外表面积、涂装总面积、周长、金额、油漆用量
- **长度支持三种方式**：30 档定尺长度下拉（1~20 m，含 11.9 m 非标定尺）、
  4 个快捷按钮（6 / 9 / 11.9 / 12 m）、任意数值直接输入
- **造价常用数据**：单价（元/t）自动算金额、油漆用量（kg/t）自动算用量
- 汇总表 16 列：型号 / 规格 / 材质 / 单重 / 单根长 / 数量 / **总长** /
  损耗 / 净重 / 计损耗 / **外表面积** / **内表面积** / **金额** / **油漆用量**，
  末行自动合计
- 导出为 18 列 Excel，含合计行

### 国标型钢表
- **447 条规格**，支持检索与一键采用

### 导出
- **导出 Excel（.xls）** —— 生成 SpreadsheetML 工作簿，Excel / WPS 双击直接打开，
  带标题样式与数字格式，数值列参与计算
- **导出 CSV** —— 加引号转义，Excel 打开不乱列
- **复制表格** —— TSV 制表符分隔，粘贴进 Excel 保持表格结构
- 桌面版弹原生保存对话框（绕过 WebView2 的 Blob 下载限制）

### 其他
- **亮 / 暗主题切换**，选择记忆到 localStorage
- **原生标题栏跟随主题**（桌面版）：网页 CSS 管不到 Win32 标题栏，
  外壳通过 DWM API 着色，详见 `desktop/README.md`
- 打印样式

## 主题配色

暗色模式对齐 **Win11 Fluent 深色调性**：Mica 底 → 卡片面板 → 控件层三级分层，
控件层比面板略亮，形成可点击暗示。全部配色由 CSS 变量驱动，无硬编码颜色。

```css
:root{
  --bg / --panel / --panel-2      /* 底色 → 面板 → 次面板 */
  --ctl / --ctl-2 / --ctl-hover   /* 控件层：输入框、下拉、按钮、chips */
  --txt / --txt-2 / --txt-3       /* 正文 / 次要 / 弱化文字 */
}
:root[data-theme="dark"]{ ... }   /* 暗色覆盖同一组变量 */
```

下拉框的展开面板由系统渲染，必须**显式指定 `option` / `optgroup` 配色**，
否则暗色下会出现浅色面板配深色文字的突兀条目。下拉箭头 SVG 也需为暗色单独提供。

### 对比度

`node test-theme.js` 从 `index.html` 直接解析变量（不手抄），
按 WCAG 2.1 相对亮度公式校验 50 项，两套主题均达标：

| 层级 | 暗色对比度 | 亮色对比度 |
|---|---|---|
| 正文 / 面板 | 13.89:1 | 16.91:1 |
| 次要文字 / 面板 | 9.43:1 | 7.54:1 |
| 弱化文字 / 面板 | 6.89:1 | 5.55:1 |
| 弱化文字 / 控件 | 5.51:1 | 4.72:1 |
| 强调色 / 面板 | 8.42:1 | 5.17:1 |
| 控件层 / 面板 | 1.25:1 | 1.18:1 |

文字一律 ≥4.5:1（WCAG AA）；控件与面板靠底色差 + 1.87:1 的描边共同区分，
与 Win11 控件的表现方式一致。

## 算法

**几何引擎** `js/geo.js` 采用**解析组合法**：截面拆分为矩形、圆角矩形、圆环、正多边形、
凹角圆角填充等解析图元，精确求得面积与形心惯性矩，再按平行轴定理合成。无数值积分误差。

槽钢采用 **GB 标准公式**直接锁定面积：

```
W = 0.00785 × [ h·d + 2t(b−d) + 0.349(R² − r²) ]
```

其中面积口径为「腹板**通高** h·d + 翼缘**伸出** 2t(b−d)」。形心与惯性矩由组合法求得，
再按 GB 精确面积缩放。

**轮廓绘制** `js/section.js` 与解析引擎共用同一套尺寸定义，但顶点独立构造，
保证「所见即所算」。所有轮廓按逆时针单圈闭合，顶点不重复、无自交；
圆角通过在角点链上插入切线圆弧实现。

### 数据复核（`test-data.js`）

三重校验，任一项超差即视为数据不可信：

1. **自洽性** —— 表内 A 与 m 必须满足 `m = A × 7.85 / 10`
   （工字钢 45 条 / 槽钢 33 条 / H型钢 20 条 **全部 0 超差**）
2. **标准公式** —— 钢管 240 条全部等于 `(D−S) × S × 0.02466`，最大绝对差 0.005 kg/m
   （2 位小数舍入）；另比对 10 个公开权威值全部一致
3. **几何对拍** —— 表值 vs 解析引擎：工字钢单重最大偏差 1.39%，
   槽钢单重 0.014%（面积已按 GB 式锁定）

另含结构完整性检查（尺寸关系、圆角相称、命名唯一）与材质密度 GB 值抽查。

### 引擎精度

| 项目 | 实测偏差 |
|---|---|
| 工字钢 单重 | < 1.5% |
| 槽钢 单重 | < 0.05% |
| 槽钢 Ix | < 5% |
| 圆钢 / 方钢 / 钢管 单重 | < 0.1% |
| 图形 vs 计算面积 | ≤ 3%，无自交、无重复顶点 |

> 图形与解析的圆角建模方式不同（图形用切线圆弧，解析用「方角减扇形」），故允许 ≤3% 面积差。
> **国标型号模式下直接查规范表值**，不受几何模型简化影响。
> 冷弯方管、矩管因焊管实际圆角随机组变化，标准重量以内置表值为准。
