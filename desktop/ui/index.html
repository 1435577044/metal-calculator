算法与精度

截面采用解析组合法：将截面拆分为矩形、圆角矩形、圆环、正多边形与凹角圆角填充等 解析图元，精确求得面积与形心惯性矩，再按平行轴定理合成。避免了数值积分误差。

已对国标型钢交叉校核（共 38 项断言）：
  • 工字钢 GB/T 706：面积、Ix 偏差 < 1.5%
  • 槽钢 GB/T 707：Ix、ix 偏差 < 3%
  • 圆钢 / 方钢 / 扁钢 / 钢管单重偏差 < 0.1%
  • 角钢 GB/T 706 单重偏差 < 1.1%
提示：国标型号模式下直接查规范表值，不受几何模型简化影响。 冷弯方管、矩管的国标重量随焊管实际圆角变化，工具优先取内置表值。
